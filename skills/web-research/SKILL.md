# Web research methodology

## Understand the question

Identify before searching: the factual claims needed, date sensitivity,
comparison dimensions, and likely authoritative sources.

## Source priority

Prefer in order:
1. official documentation
2. standards / specifications
3. government sources
4. academic papers
5. primary company sources

Use secondary sources only for interpretation, comparisons and community
views. Record which tier each key claim came from.

## Verify important claims

For important or contested claims: check multiple sources, prefer primary
evidence, record uncertainty explicitly instead of guessing.

## Track evidence

For every important finding capture: the claim, its source, publication or
update date when relevant, and a confidence level.

## Handle conflicts

If credible sources disagree: report the disagreement, never silently pick
one side, explain which source is stronger and why.

## Citation integrity

Never invent a URL, citation or source. Every [Sn] reference must correspond
to a real search result annotation or a page you fetched. If evidence cannot
be found, say so rather than filling the gap.
